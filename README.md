## ✨ Features

### 🕰️ 3D Watch Showcase
- Fully interactive 3D product presentation built with Three.js & React Three Fiber
- Smooth, physics-based rotation and drag controls
- Realistic lighting, reflections, and material shaders for a true metallic/glass feel

### 🎨 Premium Luxury UI
- Apple × Rolex–inspired visual language
- Elegant, whitespace-driven layouts
- A refined luxury color system — deep blacks, warm golds, and soft neutrals

### 🎬 Cinematic Motion Design
- Scroll-driven storytelling powered by GSAP + ScrollTrigger
- Micro-interactions and page transitions via Framer Motion
- Parallax depth effects that respond naturally to scroll velocity

### 🛒 Frontend Shopping Experience
- Add to Cart with animated feedback
- Buy Now express flow
- Polished, distraction-free Checkout UI

### 👤 User Profile Dashboard
- Profile information & account settings
- Order history
- Wishlist management
- Cart overview

### 📱 Fully Responsive
- Desktop — full cinematic experience
- Tablet — adapted layouts, preserved motion
- Mobile — touch-optimized 3D interaction

## 🎯 Design Philosophy

> **The goal was to create a luxury digital showroom experience — not a traditional e-commerce website.**

Every decision, from spacing to easing curves, was made in service of one idea: the product should
feel more premium *because* of the interface, not despite it.

- 🎬 **Cinematic Presentation** — pacing and reveals modeled after brand films, not product listings
- 💎 **Premium Interactions** — every hover, click, and drag feels intentional and tactile
- 🌊 **Smooth Animation Language** — consistent easing and timing across the entire site
- ⚪ **Minimal Luxury Design** — restraint as a design principle, not an afterthought

## ⚙️ Installation

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173` (or the port Vite assigns).

```bash
# Production build
npm run build
```
